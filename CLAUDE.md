# Klayer Island — guide for AI coding agents

Klayer Island is a native macOS app (`NotchBuddy/`); `windows/` is the Tauri version for Windows and Linux. Klay, a small animated character living in the MacBook notch, shows AI coding agent sessions (Claude Code, Gemini CLI, Antigravity and more) and a few integrations, and lets the user approve, answer, chat and drop files from the notch.

## Where things are
- `NotchBuddy/Sources/App/` — Mac-only Swift code. `NotchBuddy/Sources/KlayerIslandKit/` — Klay's BotEngine and glyph, pills, diff, models. `NotchBuddy/Resources/sounds/` — the 29 WAV sounds, generated by `scripts/gen-sounds.py`. `NotchBuddy/project.yml` — XcodeGen project (the `.xcodeproj` is generated and not committed).
- `NotchBuddy/Sources/KlayerIslandKit/PillCatalog.swift` — single source of truth for all declared pills (workspace tools, agents, AI providers, services). Every pill ID, color, category and subtitle lives here.
- `windows/src/klay/engine.ts` — Klay's look and poses, the reference for both platforms. `windows/src/klay/glyph.ts` — the Klayer glyph as segments, generated from the design system's SVG: never edit it by hand. `windows/dev/klay-preview.html` (with `npx vite`) shows every state side by side.
- `docs/SPEC.md`, `docs/INTEGRATIONS.md` — behaviour, views, states, integrations (in French). `NOTICE.md` — what comes from Coucou and what was replaced.
- `windows/` — the Tauri app for Windows and Linux: Rust in `src-tauri/`, TypeScript in `src/`, the `klayer-hook` relay in `hook/`. `windows/README.md` lists what differs from the Mac.

## Build
```
cd NotchBuddy && xcodegen && xcodebuild -scheme NotchBuddy -configuration Debug build
```
Windows and Linux: `cd windows && npm install && npm run tauri dev`

## Rules
- Swift 6, SwiftUI + AppKit. No third-party dependencies unless truly unavoidable. Klay is drawn in code (`Canvas` + `TimelineView`), no Rive/Lottie/images.
- Klay is built on the Klayer glyph: draw the glyph exactly as `glyph.ts` / `KlayGlyph.swift` give it, never reshape or recolour it (white on the dark island, white on a coloured disc for mini Klays). Nothing from Coucou's reserved assets (the Mochi character, its outfits, icons, sounds, media) may come back.
- Secrets live in the Keychain, never on disk or in git.
- No telemetry. Network calls only to services the user configured.
- Never block Claude Code: if the app doesn't answer, the hook exits immediately.
- Never overwrite `~/.claude/settings.json`: dated backup, merge, show the diff, write only after the user confirms.
- Never send an email or approve a Claude Code or Codex permission without an explicit click.
- Performance: 0 % CPU when the island is hidden.
- Keep the bundle identifier `ai.klayer.island` (Keychain items, preferences and permissions depend on it).
- Never restyle what already ships (pills, cards, Settings, chat…). Change the look of an existing view only when explicitly asked.
- Pill IDs are stable contract values (Keychain, UserDefaults, hook routing): never rename an existing pill ID.
- New views follow the existing app style.
- Every release adds its CHANGELOG.md section and commits the regenerated Info.plist with the new version. Internal distribution only: anything published outside Klayer is approved by a founder first.
